Privacy

The CLI sends requests only to the API base URL in your environment file. It sends no telemetry to this project or Sociobot.

The CLI replaces sensitive headers and configured secret values before writing the proof bundle. Response bodies can contain other private data, so review each report before sharing it.

The documentation site has no analytics, advertising, accounts, cookies, or remote scripts. Its service worker caches public pages on your device for offline reading.

Use your browser’s site-data controls to remove that offline cache.
