01 / Install the local CLI

Install the CLI

Install from the repository. Then run the bundled demo without an account or API setup.

Terminal
cargo install --git https://github.com/B-Divyesh/sf-arazzo-proof-runner

03 / From source to report

How it works

  1. 01

    Choose an Arazzo file

    Point the CLI to a local workflow and an explicit environment file.

  2. 02

    Run against an environment

    The CLI calls only the base URL selected in that file.

  3. 03

    Open the redacted report

    Review each request, response, output, and assertion by workflow step.

04 / Boundaries

What the CLI does not do

No hosted runner

The site does not receive workflow files or proof bundles. Your selected API still receives the requests you run.

No secret discovery

The CLI redacts configured secrets and sensitive headers. Review response bodies before sharing a report.

05 / Documented boundary

Supported Arazzo features and explicit limits

✓

Supported features

  • Local OpenAPI 3.0 and 3.1 sources
  • Operation IDs and local operation paths
  • Path, query, header, and cookie parameters
  • JSON payloads and chained outputs
  • Six comparison operators
—

Unsupported features

  • Remote sources and external references
  • OAuth flows and callbacks
  • JSONPath criteria
  • Success and failure actions
  • Non-JSON request bodies
Unsupported Arazzo features return an error.

The CLI names the step and feature, exits 2, and writes no partial proof bundle.
